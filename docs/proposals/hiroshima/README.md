## 要確認事項（作成にあたっての前提）

- 提出日を **2026年8月27日** としています（ロードマップ資料の提示日に合わせています）。
- 宛先を「広島市 御中」としています。
- 実施スケジュール（P24）の各工程の期間は目安として置いた案です。
- P25 のご確認事項は、原資料の「広島市への確認事項」欄が空欄だったため、
  各要件のワイヤーフレーム注記から想定される論点を整理したものです。

## 再生成

`build/build_deck.py` が生成スクリプトです。ベースとなる pptx とワイヤーフレーム PDF から
切り出した画像（`build/img/`）を参照します。スクリプト冒頭の `BASE` / `IMG` / `OUT` の
パスを環境に合わせて変更したうえで実行してください。

```
pip install python-pptx
python3 build/build_deck.py
```
