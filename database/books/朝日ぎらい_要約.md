# 『朝日ぎらい よりよい世界のためのリベラル進化論』

- 著者: 橘玲(たちばな・あきら)
- 出版社: 朝日新聞出版(朝日新書671)
- 刊行: 2018年6月30日 第1刷
- 著者略歴: 作家。1959年生まれ。2002年国際金融小説『マネーロンダリング』でデビュー。『言ってはいけない 残酷すぎる真実』(新潮新書)が48万部超のベストセラー新書大賞2017。他に『(日本人)』『お金持ちになれる黄金の羽根の拾い方』など著書多数。
- 著者の政治的立場: 本人いわく「リベラル」。「普遍的人権」という近代の虚構を最大限尊重し、いわれなき差別のない自由な社会を理想とする。

## 1. 前書き・あとがき・あらすじまとめ

**まえがき**で著者は、タイトルの「朝日ぎらい」は井上章一のベストセラー『京都ぎらい』からの拝借であり、朝日新聞そのものを罵倒する本ではないと断っている。関心の中心は「日本でリベラル(戦後民主主義)が嫌われているのはなぜか」という原理的な問いで、インターネット上の不毛な罵詈雑言の応酬からは距離を置くと宣言する。

本書の骨格は、①日本では「リベラル」を自称する安倍政権が実際には改革路線(右傾化)を進め、野党が逆に「変わらない」保守の立場を取るという逆転現象の指摘(PART1)、②アイデンティティ政治が「正義」を振りかざす自己目的化した対立を生む病理(PART2)、③「リベラル(グローバル・リバタニア)」と「保守(ローカル・ドメスティックス)」という価値観の空間的分断の構造(PART3)、④進化心理学・行動遺伝学による「リベラル/保守」という性格傾向そのものの起源の解明(PART4)、という4段階で構成されている。

**あとがき**では、著者は自身を「リバタリアン部族」に属すると位置づけ、日本が重層的な身分制社会であることへの批判を、差別撤廃やハラスメントの廃止を求める「リベラル」の姿勢と同じだと述べる。「リベラル」を名乗るなら日本的雇用そのものを壊す側に立つべきで、朝日新聞を含む「リベラルな新聞社」が実際には年功序列・終身雇用・正社員制度という身分制を温存している矛盾を強く批判する。最後は「朝日新聞の勇気と良識を示したものと考えたい」と、朝日新聞への一定の期待を残して締めくくっている。

## 2. 各章の結論と根拠(箇条書き)

### PART1 「リベラル」と「保守」が逆転する不思議の国
**結論**: 世界的な「リベラル化」の潮流の中で、日本では「保守」であるはずの安倍政権が実質的にリベラル(改革)路線を進め、「リベラル」を自称する野党・メディアが実際には変化を拒む保守そのものになっている、という逆転現象が起きている。

- 安倍政権支持率は若い世代ほど高く(18〜19歳男性で55%)、これは若者が「保守化」したからではなく、同一労働同一賃金・働き方改革などリベラルな政策を安倍政権自身が進めているため
- 野党(共産党含む)は改憲・安保法制・消費税など「変わらないこと」に固執する勢力として、相対的に「保守」の位置に押し出された
- 小泉純一郎・橋下徹・小池百合子という「3人のポピュリスト」は、既得権(終身雇用・年功序列・労働組合など)を守ろうとする「オールドリベラル」を標的にすることで若者の支持を集めた
- 世界的にも「リベラル」は1930年代のソ連型計画経済批判から出発したネオリベラリズムに意味がシフトしており、定義そのものが国・時代で揺れ動いている
- 一方で世界全体では、人種差別の減少・同性婚の拡大・フェミニズムの浸透など、長期的な「リベラル化」の潮流自体は明確に進行している(具体的データはPART1第2章)

### PART2 アイデンティティという病
**結論**: 人種・ジェンダー・国籍などの属性(アイデンティティ)を軸にした「正義」の主張は、本来の差別解消という目的を離れ、相手を攻撃し自分の道徳的優位を誇示するための自己目的化した対立(「正義依存症」)に陥りやすい。これは欧米のリベラル対保守(ネトウヨ的白人至上主義への反発等)とも、日本の「嫌韓・反中・朝日ぎらい」とも共通する構造である。

- アメリカでは「人種差別をしない」と自認するリベラルほど、無意識の偏見テスト(IAT)で潜在的な差別意識が検出されるという逆説がある(PART4で詳述される実験と同系統の議論)
- 日本人の「アイデンティティ主義」(在日特権論、慰安婦問題を巡る「寝取られ」的な感情論など)は、欧米のアイデンティティ政治と同型の心理メカニズムで駆動されている
- 「正義依存症」は、攻撃対象への反発そのものが目的化し、相手の主張の妥当性よりも「自分が正しい側にいる」ことの確認が優先される
- 右派論壇にもポストモダン的な相対主義やエンターテインメント化が浸透し、「愛国」を掲げる思想的リーダーが新たに誕生している
- 「加害」と「被害」を語る際の非対称性(誰が加害者/被害者として語る資格を持つか)が、対立をさらに先鋭化させる

### PART3 リバタニアとドメスティックス
**結論**: 現代世界は、国境を越えて同じ価値観を共有する知識層・富裕層からなる「リバタニア(リベラル共和国)」と、国境に根ざした生活を送る「ドメスティックス」という、事実上の二つの"国"に分断されている。グローバル空間では圧倒的多数がリベラルだが、ドメスティックス側では保守が優勢で、この非対称な力関係がナショナリズムの反発(右傾化)を生んでいる。

- リバタニアの住人は「国家よりも個人の自己決定権や共同体の自律性を優先する」という信念(自由=Liberty)を共有する
- リバタニアとドメスティックスを合わせても、アメリカの先進国の総人口7億人の7割程度を占めるにすぎず、グローバルな「普遍」の主張が必ずしも多数派の実感と一致しない
- ロールズの「無知のヴェール」「格差原理」のようなリベラルの理論的正統化がある一方、チンパンジーの行動研究からも「公正さ」への反応(互恵性の感覚)が見られ、道徳感覚自体の進化的起源が示唆される
- サイバーリバタリアン(テクノロジーを梃子に自由を追求する勢力)という第4の政治思想が、従来の「リベラル/保守」の対立軸に新たに加わりつつある
- 日本の右翼・保守の「国際社会ではリベラル、若者にはネオリベ、既存支持層には保守、アイデンティティ主義者にはネトウヨ」という4戦略の組み合わせが「安倍一強」の秘密であり、これは国際的に孤立しがちな「右」が唯一安定して支持を広げられる現実的な布陣である

### PART4 「リベラル」と「保守」の進化論
**結論**: 「リベラル」と「保守」という政治的態度は、育ちや教育だけで形成されるものではなく、進化心理学的に根の深い性格特性(新奇好み=ネオフィリア/新奇嫌い=ネオフォビア)や、相当程度の遺伝的要因によって規定されている。知能・言語運用能力の高さとリベラルな政治的態度には明確な相関があり、これが「リベラルはなぜ金持ちか」という現象の説明にもなる。

- 道徳心理学者ジョナサン・ハイトの6つの道徳基盤(ケア/公正/自由/忠誠/権威/神聖)のうち、リベラルはケアと公正のみを重視し、保守は6つすべてをバランスよく重視する傾向がある(「きれいごとはなぜうさん臭いのか」の章の中核)
- 「道徳の貯金箱」実験: 一度道徳的な選択(性差別を否定する等)をした人ほど、その後は無意識に差別的な判断を許容しやすくなる(モラル・ライセンシング効果)
- 政治的態度の遺伝率は平均32%(資本主義39%、平和主義38%など)で、環境より遺伝の影響が無視できない水準にあることが双生児研究から示されている
- 知能(特に言語運用能力)が高い子どもほど23歳時点でリベラルになりやすく、知能が低い子どもほど保守になりやすいという複数の縦断研究結果がある
- ネオフィリア(新奇好み)とネオフォビア(新奇嫌い)という性格特性が、進化的には「食料の枯渇」や「未知の病原体」に対する異なる生存戦略(集団内でリスクを分散する仕組み)として共存してきた
- 「イデオロギーは匂うか」実験: 被験者は自分と同じ政治思想の人の体臭(汗の匂い)を無意識に好み、恋人選びにおいても政治的態度の一致が重要な要因になっている(進化的な「同類交配」のメカニズム)

**エピローグ(サイバー空間のイデオロギー戦争)**: 今後の思想対立の主戦場はAIなどのテクノロジーが社会を最適設計するサイバー空間に移る。サイバーリバタリアン右派(ナッジで個人を「正しい選択」に誘導する設計主義)とサイバーリバタリアン左派(ベーシックインカムでAI時代のユートピアを実現する構想)という新しい対立軸が、従来の「リベラル/保守」を再編しつつあるという見通しで本書を締めくくる。

## 3. 筆者が言いたいことをひと言で言うと何か

**「リベラル」と「保守」は単なる政治的立場の違いではなく、進化的に根を持つ性格傾向(新奇好み vs 新奇嫌い)の表れであり、日本では「リベラル」を自称する勢力がむしろ既得権を守る「保守」として機能し、真にリベラルな改革(日本的雇用の解体、身分制の撤廃)を進めているのは皮肉にも「保守」とされる側である、という逆転現象こそが日本社会の本質的なねじれである。**

## 4. この本を受けて渡辺さんがすべきこと

- **「リベラル/保守」のラベルで人や政策を判断する前に、実質的な中身(既得権を守るか壊すか)を見る習慣を持つ**: 自治体向けシステム提案の現場でも、「改革」「DX」を掲げる側が実は既得権を温存し、慎重な側が合理的な抵抗をしているだけ、という構図は頻繁に起こりうる。ラベルより実態を見る視点は営業・提案の精度を上げる
- **自分自身の政治的態度を「正しさ」ではなく「進化的な性格傾向」として距離を置いて眺める**: 新奇好み・新奇嫌いという軸は、仕事での省力化志向(効率化=新奇好み的側面)と、変化を急がない慎重さ(保守的側面)が同居する渡辺さん自身の判断パターンの理解にも応用できる
- **道徳的優位性の誇示(「正義依存症」)が議論を硬直させる構造を意識する**: 社内の対中感情論やSNS上の対立を見る際、「誰が正しいか」より「なぜその対立が自己目的化しているか」という一段引いた見方をすると、無駄な摩擦に巻き込まれずに済む
- **『未完の中国文化大革命』で持った「社会主義と暴力の構造的関係」への関心は、本書の射程外**: 本書はあくまで欧米・日本の「リベラル/保守」対立の心理学的・進化論的分析に特化しており、全体主義論や比較政治体制論とは別系統。その関心を深めたいなら、前回提案した『全体主義の起原』や『共産主義黒書』の方が直接的な答えになる
