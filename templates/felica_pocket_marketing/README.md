# フェリカポケットマーケティング株式会社 提案書フォーマット

今後、同社フォーマットに合わせたパワーポイント資料を作成する際の参照用マスター。

元になったファイル：
- `template1.pptx`：北区産業振興課向け提案書（本文ページのサンプルが豊富）
- `template2.pptx`：神戸市教育委員会向け提案書「KOBE◆KATSU」コベカツポイント（表紙・本文マスターの抽出元）

このフォルダの `避難所へGo_機能拡張ロードマップ_FPM書式.pptx` は、広島市防災アプリ「避難所へGo!」のロードマップ資料に、本フォーマットを適用したサンプル成果物。`build_fpm.js` がその生成スクリプト（pptxgenjs）。同様の依頼が来たら、このスクリプトを土台に内容だけ差し替えるのが最短。

## 再生成の手順

```bash
cd templates/felica_pocket_marketing
npm install pptxgenjs   # 未インストールの場合
node build_fpm.js
```

内容（タイトル・カード内容など）を変えたい場合は `build_fpm.js` 内の `phases` 配列や各 `addText` の文字列を編集する。ロゴ画像は `assets/fpm_logo.png` を参照しているので、フォルダごと保存しておくこと。

## 注意点（次回作成時に踏むと危ない落とし穴）

- スライドは4:3。うっかりワイド（13.3×7.5）で作らないこと。
- タイトル下の区切り線とフッターの段差ラインは、テンプレートのマスターXML（`slideMaster1.xml`）に実在する要素。一般的なデザインガイドラインでは「タイトル下の装飾線は入れない」のが原則だが、この会社のフォーマットに合わせる場合は例外的に踏襲する。
- react-iconsで作ったアイコンをsharpでPNG化する際、`fill="currentColor"`をそのまま残すと黒くレンダリングされる（resveg/sharpがCSSのcurrentColorを解決できないため）。`fill`/`stroke`属性を実際の色コードに置換してから書き出すこと。
- 本サンドボックス環境ではLibreOfficeの`libreoffice-impress`等のコンポーネントが標準では入っておらず、`soffice --convert-to pdf`が「source file could not be loaded」で失敗する。QA画像化の前に `apt-get install -y libreoffice-impress libreoffice-writer libreoffice-calc` が必要。
